Curriculum Overview ​

Status: Phase 2 -- Master Curriculum Plan

This document lists every lesson in the Dutch B1 Curriculum in sequence. This is your roadmap for lesson creation.

Each lesson corresponds to ONE competency from docs/COMPETENCY_MAP.md.

How to Use This Document ​

  1. For Planning: See all 28 lessons at a glance in order
  2. For Research: Each lesson has a research prompt template location
  3. For Creation: Create lessons one at a time from top to bottom
  4. For Status Tracking: Mark each as Pending → In Progress → Complete

Summary ​

  • Total Lessons: 34 (28 content lessons + 4 review lessons)
  • Review Lessons: After every 5-7 lessons, one review lesson with no new material
  • Status: All Pending (ready for research)

Next Steps ​

  1. Choose Lesson: Start with A0-01 (or any lesson)
  2. Research: Use the research request template to gather information externally
  3. Return: Paste your research output here
  4. Update: I integrate the research into the lesson and update status
  5. Repeat: Move to the next lesson

Each lesson will have a research request that asks for:

  • Grammar concepts and explanations
  • Vocabulary (25-35 words)
  • Example sentences and dialogues
  • Cultural notes
  • Exercises (types and quantity)
  • Assessment criteria
